# JFT Basic A2 Trainer

インドネシア人学習者向けの JFT Basic A2 練習アプリです。

## 開き方

`index.html` をブラウザで開きます。

## できること

- Grammar / Expression の切り替え
- 文法カテゴリ別の絞り込み
- 140問の選択式練習
- 毎回ランダムに20問出るテストモード
- 文字・語彙、漢字、読解問題
- 60分タイマーつき50問模擬テストモード
- 正誤判定とインドネシア語の解説
- 間違えた問題の Review
- Bank Soal で全問題の確認と検索
- localStorage による進捗保存

## ファイル

- `index.html`: 画面構造
- `styles.css`: レイアウトとデザイン
- `app.js`: 問題データと学習ロジック
